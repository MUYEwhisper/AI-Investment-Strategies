# 2026-11-01 本地智投连续提问修复

## 原因与修复

本地回答结束时，`renderModel({ running: true })` 在 `state.busy` 仍为 `true` 时计算输入框和发送按钮的 `disabled`。随后 `finally` 只清理忙碌状态，没有重新渲染这两个控件，导致模型已就绪、回答已显示，但无法输入下一问。

`desktop/local-ai.html` 现在先清理忙碌状态，再用现有 `renderModel` 同步输入框与按钮，最后恢复焦点。模型不可用时继续禁用发送，流式生成期间仍禁止并发请求。
